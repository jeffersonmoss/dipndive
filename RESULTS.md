## 4. Where the plan proved wrong or incomplete

1. Paywall detection by length (3.3.6, "under ~800 characters") does not work. NYT served 2,060 characters of teaser text to a plain fetch, which was summarized as if it were the whole article (a silent-wrong result). Fix implemented: pages declaring schema.org `isAccessibleForFree: false` fail as `no_article_text`. Sites without that marker can still leak a teaser; consider also a minimum length relative to the page's own declared word count.
2. `subtitles` keys are not always plain language codes. A German video had `de-CcQ45jRV4-E` as its manual track name. The 3.3.4 order had to be extended to match regional or suffixed codes by language prefix (implemented in `pick_track`).
3. 3.3.4 says automatic English only with `en-orig` or metadata `language` en. Holds: every auto-caption video tested had `en-orig`. The auto track is rolling VTT or json3 with no punctuation; summaries were still good.
4. `--ignore-user-config` and CODEX_HOME: a codex call with an empty CODEX_HOME still populates that folder (sqlite state, installation_id, skills, .tmp), so "minimal config.toml only" is true of what we write, not of what codex adds. No auth.json was created.
5. Codex on an unauthenticated home does not say "not logged in" at exec time; it retries a websocket and reports 401 after about 20 s. `login status` (used by `/health`) is the fast check; the module could call it first.
6. The 3.4.1 Claude flags work as written on Claude Code 2.1.285 (`--safe-mode`, `--strict-mcp-config`, `--tools ""`, `--no-session-persistence`, `--system-prompt`). The JSON output includes `permission_denials` and `num_turns`, both useful loud-failure checks (the module fails on any denial).
